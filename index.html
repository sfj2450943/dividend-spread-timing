数据来源：Wind 万得金融数据服务（index_data.get_index_kline）· 中证红利全收益 H00922.CSI · 万得全A 881001.WI（Wind 口径为全收益指数）· 代理口径 H00985.CSI 中证全指全收益。数据来源于万得 Wind 金融数据服务。
口径说明：40 日收益差 = 中证红利全收益 40 日收益率 − 市场指数 40 日收益率，逐日滚动。窗口 40 个交易日取自原策略设定。
年线说明：收益差年线 = 40 日收益差的 242 日均线（约一年交易日）。其上穿 0 轴代表中证红利相对市场趋势转强，下穿 0 轴则为转弱。该信号源自张翼轸 EarlETF《轮动三棱镜使用指南：三套指标，五个用法》。在「简单版」中它仅作趋势参考、不参与买入线/卖出线策略的信号计算；在「组合版」中它作为状态闸门参与分档。
组合方案说明：年线在 0 轴上方时卖出线放宽（默认 +8%），年线在 0 轴下方时卖出线收紧（默认 +5%）且仓位上限压到「弱市上限」（默认 50%），年线穿轴当日按新档位调仓一次；「强市加仓」（默认 +0%）在 100% 基础上放大仓位，超出部分按「融资成本」（默认 6%/年）逐日计息。默认配置不含杠杆，历史回测（2015-02 ~ 2026-09）累计 +227.99%、年化 +11.17%、最大回撤 −22.39%；一旦启用「强市加仓 50%」，同一区间累计升至 +339.91%~+412.31%（含 / 不含融资成本），但最大回撤扩大到 −32.19%~−33.37%，且杠杆仓位在快速下跌中存在强制平仓风险。
回测假设：T 日收盘观察信号、T 日收盘成交（0 日延迟，故实盘会有收盘集合竞价/滑点偏差，严格实盘宜按次日开盘或次日收盘执行）；「单边成本」默认 0 bps，可拖动检验成本敏感性（P2 口径下 20 bps 仍为 +207.36%）；持仓期间按指数全收益计算，未考虑 ETF 跟踪误差与管理费。组合版的「区间收益」按含成本净值逐段相除得出，各段连乘 = 累计收益。
