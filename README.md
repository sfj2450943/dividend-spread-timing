# 中证红利 · 40日收益差择时看板

把「中证红利相对全市场的 40 日超额收益」做成均值回归择时信号，并可视化回测。
原策略思路来自公众号「ETF大白」2024-08-07《神秘的40日收益差：用红利打败红利！》。

## 指标定义

```
40日收益差 = 中证红利全收益 40日收益率 − 市场指数 40日收益率    （逐日滚动）
```

- 收益差跌破 **买入线** → T+1 收盘买入中证红利
- 收益差涨破 **卖出线** → T+1 收盘卖出
- 其余时间维持原仓位

窗口 40 个交易日取自原策略设定（基于兴业证券统计的优化，A 股行情持续性约两个月）。

## 趋势副指标：收益差年线 242 日

主图额外叠加一根「收益差年线」＝ 40 日收益差的 **242 日均线**（约一年交易日），并在其上穿/下穿 0 轴处标注三角。

- **上穿 0 轴** → 中证红利相对市场趋势转强
- **下穿 0 轴** → 趋势转弱

信号出处：公众号「张翼轸Earl / EarlETF」2026-04-07《轮动三棱镜使用指南：三套指标，五个用法》用法❺。
原文同时提醒 40 日收益差**对起点敏感**（40 个交易日前的大涨大跌会形成干扰），作者另加「比值 14 日 RSI」做辅助校验。

该年线**仅作趋势参考，不参与**买入线/卖出线策略的信号计算，KPI 第 5 卡显示其数值、0 轴上下位置与最近一次穿轴日期。
全历史（Wind 口径）共 9 次穿轴：上穿 4 次、下穿 5 次。

## 本地运行

**方式一：直接双击 `index.html`**（推荐日常查看）
页面会读取同目录 `data/data.js` 里内联的数据，不依赖 HTTP 服务。
> 前提是 `data/data.js` 存在（由数据管道生成、已随仓库提交）；需要联网加载 ECharts CDN。

**方式二：起本地 HTTP 服务**（开发调试用，数据走 `fetch(data/data.json)`）
```bash
export WIND_API_KEY=你的Key
python3 scripts/fetch_data.py --out data/data.json   # 同时生成 data/data.js
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 加载顺序：优先用 `data/data.js` 内联数据，取不到时回退 `fetch(data/data.json)`。
> 因此早期「双击打不开」的问题已消除；若两个文件都缺失，页面会给出明确提示。

## 部署到 GitHub Pages

1. 新建仓库并推送本目录。
2. **Settings → Secrets and variables → Actions → New repository secret**，
   名称 `WIND_API_KEY`，值为你的 Wind API Key。
3. **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`。
4. **Actions** 页手动跑一次 `更新 40日收益差数据`，确认能拿到数据并成功提交。
5. 之后每个交易日北京时间 16:30 自动更新。

## 风险与已知限制

- **Wind 额度**：每个交易日只调用 3 次接口，结果落盘缓存，正常不会触发限额。
- **前视偏差**：信号在 T 日收盘确认、T+1 日收盘执行，已做一日延迟；但收盘价同时用于计算指标与执行，实盘会有微小滑点差。
- **交易成本**：回测未计佣金、冲击成本与 ETF 跟踪误差、管理费。实际年化超额会低于回测值。
- **参数敏感性**：买/卖线是核心参数，不同设置下年化超额差异明显，不要只看最优参数。页面提供滑杆自行检验稳健性。
- **代理口径偏差**：中证全指与万得全A 的 40 日收益差平均相差 0.41pct，极端处最大 6.59pct，阈值附近信号可能翻转；严谨结论请用 Wind 原口径。
